# The Pandora Machine Opensource Code
info about project

**Stack**:
    - App: python flet
    - Firmware: PlatformIO
    - ESP32 and 3D-printing

## Set up the project
1. 3D-print all the parts (or create a housing with another way)
2. Assemble the machine (instructions)[]
3. Upload a firmware in ESP32 (instructions)[]
4. Turn on the machine
5. Download the app and connect to ESP32
All done!

## Control app
You need to download an app
connect with bluetooth

## BOM
Controller ESP32
Mini-pumps
Big pumps
Flasks
Gates
Pin extenders

## Things you must prepare yourself
Sweet solution 1:1
    1 liter of solution is nearly 620 g of white sugar and 620 ml of tap water

Sour solution 1:10
    1 liter of solution is nearly 100 g of citric acid powder and 1 liter of tap water
